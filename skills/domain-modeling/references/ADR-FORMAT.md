# Architecture Decision Record Format

Use the repository's established ADR location, naming, and template. Use the
following compact format only when the repository has adopted it:

```md
# {Short title of the decision}

{In one to three sentences, state the context, decision, and reason.}
```

Add sections such as `Status`, `Considered Options`, or `Consequences` only
when they preserve information a future reader genuinely needs. Follow
existing numbering; never guess a destination or naming convention when none
exists.

Create an ADR only when the decision is difficult to reverse, surprising
without context, and the result of a real trade-off. All three conditions are
required.
